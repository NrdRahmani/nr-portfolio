# nr-portfolio professional V2

Replace the files in your current `nr-portfolio` folder with `index.html` and `style.css`.

Then run:

git add .
git commit -m "Professional portfolio redesign"
git push

GitHub Pages will redeploy automatically.

Notes:
- No external image dependency: the industrial visuals are built with CSS.
- Planned projects remain explicitly labeled as planned/demo case studies.
- The site remains employer-friendly and does not label you Founder, CEO or Freelancer.
